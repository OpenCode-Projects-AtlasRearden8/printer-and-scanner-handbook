# Quick start: five fixes, right now

If you're here mid-emergency: print isn't moving, the deadline is real. This page is the handbook compressed to a sticky note.

## 1. Cancel all print jobs, then print once

Open the print queue (Windows: Settings → Printers & scanners → your printer → *Open print queue*; Mac: System Settings → Printers). Cancel everything. Send one page. That's it—that fixes more "broken" printers than any other single act.

## 2. Check the printer's own screen

Your printer usually knows what's wrong with it. Read its panel before trusting the computer's dialog.

## 3. The 30-second unplug

Printer off, unplugged, count to thirty, plug back in, wait for it to settle, try again. Not optional ritual—network stacks genuinely need a moment to reset.

## 4. Same Wi-Fi, same name

Confirm the device and the printer are on the same network name (and that the print dialog is aimed at the printer you actually own—no "Copy 1" impostors).

## 5. If the page prints but looks wrong

Garbled symbols = reinstall driver. Faded/streaks = head-clean or supplies. See [chapter 7](07-driver-and-spooler-fixes.html), fifth stop.
