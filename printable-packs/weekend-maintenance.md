# Weekend Maintenance Tick-Sheet

*Five minutes, once a month. Dull on purpose—dull means no emergencies. From Chapter 1's ritual.*

<div class="pack-meta">Hang near the printer. Date it each time: ____________ (month/year)</div>

## The five-minute ritual

- [ ] **Print something** (a test page or a colorful page) so nozzles stay clear
- [ ] **Wipe the scanner glass** — damp microfiber, then dry
- [ ] **Blow out the paper tray area** — dust is a jam in training
- [ ] **Power mode check** — printer asleep or on (not hard-cycled daily)
- [ ] **Field any blinking lights** — glance at the error panel, note anything new

## Optional, worth it every 3 months

- [ ] Nozzle check page on inkjets (run head-clean only if stripes appear)
- [ ] Laser: cleaning page / drum inspection
- [ ] ADF path: quick wipe, check for stray scraps
- [ ] Check spare ink/toner stock — reorder *before* empty, not after
- [ ] Firmware update if the maker's app has been nudging me

## Things that predict next month's trouble

Watch for these; each one has a chapter:

| Warning sign | Chapter |
| --- | --- |
| "Offline" flickering every couple weeks | Ch 3 — Wi-Fi / DHCP reservation |
| Slow first prints, quick after | Ch 5 — supplies nearing end |
| One color always faded | Ch 7 — check that cartridge's channel |
| Jam every duplex job | Ch 6 — paper brand, fan the ream |
| Queue jobs that linger | Ch 7 — spooler hygiene |
