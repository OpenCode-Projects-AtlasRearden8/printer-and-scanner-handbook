# Printer Rescue Checklist

*Print one. Tape it inside the cabinet where the printer lives. Breathe.*

<div class="pack-meta">Keep with: printer manual • Wi-Fi password • ink/toner spares</div>

## Step 1 — Before anything clever

- [ ] Printer has power, no error icon on its own screen
- [ ] Paper tray has paper, loaded square, under the fill line
- [ ] I read the error on the printer's screen first (it usually knows)

## Step 2 — The queue (fixes half of everything)

- [ ] Opened the print queue
- [ ] Cancelled **all** jobs, including the stuck one
- [ ] Sent **one** test page

## Step 3 — One-way street test

- [ ] Printer can copy/test-page from its own panel?
  - **No** → printer-side: paper path, supplies, phantom-jam sensor sweep
  - **Yes** → computer-side: continue below

## Step 4 — The network

- [ ] Print dialog aimed at the right printer (no "Copy 1" impostors)
- [ ] Computer and printer on the same Wi-Fi name
- [ ] Router: no guest-network / AP-isolation splitting them apart
- [ ] Printer set to a fixed IP (DHCP reservation) so this stops recurring

## Step 5 — The 30-second unplug

- [ ] Printer off, unplugged, count 30, plug in, let it settle, retry

## Step 6 — Still ugly output?

| Print looks like | Do this |
| --- | --- |
| Gibberish symbols | Reinstall the driver (delete printer, re-add) |
| Faded / streaky / striped | Head-clean once or twice, then supplies |
| Ghosting / smears (laser) | Run cleaning page; check drum life |
| Wrinkled paper | Fresh ream, fanned; correct tray size setting |

## Step 7 — The escalation ladder

1. Restart printer (30 s) → router → computer, in that order
2. Print from a different device to split the problem in half
3. Firmware update from the maker's app (don't power off mid-update)
4. Search: *model number + exact error text*

## When to stop

- [ ] It printed
- [ ] Or I did 15 honest minutes and tomorrow's version of me gets the rest
